# Alignbox Chat Application

A real-time group chat application built with HTML, CSS, JavaScript, Node.js, and MySQL, featuring anonymous messaging capabilities.

##  Quick Start Guide

# Alignbox Chat (Node.js + MySQL)  

**Stack:** Node.js, Express, Socket.IO, MySQL, HTML/CSS/JS  

## Setup
1. Create a MySQL database name as alignbox_chat and run   
2. in .env file add your DB credentials  
3. Install dependencies: `npm install`  
4. Start server: `npm start`  
5. Open: [http://localhost:3000](http://localhost:3000)  

**Env Variables:** `PORT, DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME`
