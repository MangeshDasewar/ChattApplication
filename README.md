**💬 ChattApplication - Anonymous Group Chat**
A real-time group chat application built using Node.js, Express, Socket.IO, and MySQL.
Supports anonymous messaging, group chats, and mobile-first responsive design, with persistent message storage.


**📌 Features**

Real-time Messaging: Send and receive messages instantly.

Anonymous Mode: Long-press input to toggle anonymous messages.

Group Chat: Multiple users can join and chat in groups.

Message Persistence: All messages are stored in MySQL database.

Mobile-Friendly UI: Fully responsive and intuitive interface.


**🛠 Technologies Used**

Backend: Node.js, Express.js, Socket.IO

Frontend: HTML, CSS, JavaScript (Vanilla)

Database: MySQL
